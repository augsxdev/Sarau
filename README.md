# SARAU — Bar & Social Club

Site estático responsivo feito em HTML, CSS e JavaScript. Não precisa instalar dependências.

## Executar localmente

Na pasta do projeto, rode:

```sh
python3 -m http.server 8000
```

Abra `http://localhost:8000` no navegador. Sirva o site por HTTP para o vídeo do hero carregar corretamente.

## Conteúdo

- `index.html`: estrutura e conteúdo da página.
- `styles.css`: identidade visual, layout responsivo e preferência por movimento reduzido.
- `script.js`: menu móvel, data mínima e estado do formulário demonstrativo.
- `assets/`: vídeo de abertura e imagem estática de fallback.

O formulário de reservas ainda precisa ser conectado ao canal oficial do SARAU antes de receber pedidos.
